# Java 8 (Released March 2014)
Lambda Expressions: Introduced functional programming features.
Stream API: Allowed functional-style operations on collections.
Date and Time API (java.time): Replaced the old java.util.Date and Calendar classes.
Optional Class: Helped avoid null checks.
Default Methods: Allowed adding new methods to interfaces without breaking existing implementations.

# Java 9 (Released September 2017)
Java Platform Module System (JPMS): Introduced modularity for better encapsulation and dependency management.

# Java 10 (Released March 2018)
Local Variable Type Inference (var): Allowed type inference for local variables.[ Only for variable inside method ]
Application Class-Data Sharing (CDS): Improved startup performance.
Time-Based Release Versions: Introduced a new release model with shorter cycles.

# Java 11 (Released September 2018)
`HTTP Client (java.net.http)`: Added a modern HTTP client API.[Supports sync & async, used mainly for http request 
simpler api call, does not support reactive stream and back pressure handling]
Launch Single-File Source-Code Programs: Allowed running Java programs from a single file.
Var Handles: Introduced a low-level mechanism for working with variables.

# Java 12 (Released March 2019)
Switch Expressions (Preview): Simplified switch statements.
Text Blocks: Allowed multi-line string literals.
Thread-Local Handshakes: Improved thread-local variable handling.

# Java 13 (Released September 2019)
Enhanced Switch Expressions: Made switch expressions a standard feature.
Pattern Matching for instanceof: Simplified type checks and casts.
Reimplement the Legacy DatagramSocket API: Improved performance and reliability.

# Java 14 (Released March 2020)
Records: Introduced a concise way to declare classes that hold data.
JEP 358: Helpful NullPointerExceptions: Improved NullPointerException messages.
Foreign-Memory Access API (Preview): Allowed Java programs to access foreign memory.

# Java 15 (Released September 2020)
Sealed Classes (Preview): Allowed defining classes that restrict which other classes can extend them.
Hidden Classes: Improved security and performance.
Z Garbage Collector (ZGC): Introduced a scalable low-latency garbage collector.

# Java 16 (Released March 2021)
Records (Second Preview): Further enhancements to records.
Pattern Matching for instanceof (Second Preview): Improved pattern matching features.
Foreign-Memory Access API (Second Preview): Continued enhancements to foreign memory access.

# Java 17 (Released September 2021)
Sealed Classes (Second Preview): Made sealed classes a standard feature.
Pattern Matching for instanceof (Third Preview): Further enhancements to pattern matching.
JEP 376: Enhanced Pseudo-Random Number Generators: Improved random number generation.

# Java 18 (Released March 2022)

Vector API (Preview): Added support for vectorized operations.
Foreign-Memory Access API (Third Preview): Continued enhancements to foreign memory access.

# Java 19 (Released September 2022)
Structured Concurrency (Second Preview): Further enhancements to structured concurrency.
Vector API (Third Preview): Continued enhancements to vectorized operations.
Foreign-Memory Access API (Fourth Preview): Continued enhancements to foreign memory access.
